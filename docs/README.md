# Project documentation

This folder holds **product and engineering documentation** that is **not** part of the agile / PM system.

## What belongs here
- Architecture overviews and diagrams
- API specifications and integration notes
- User or operator guides for the shipped product
- ADRs or design notes that are not already under `project-management/architecture-decision-records/`

## What stays elsewhere
- **Backlog, sprints, processes, templates**: `project-management/`
- **Requirements / orchestration artifacts**: `artifacts/`
- **Persona prompts**: `personas/`
- **Release history**: `RELEASE_NOTES.md` (repository root)

## Entry points
- Repository overview: [README.md](../README.md) at the repo root
- PM workflow for AI and humans: [project-management/INDEX.md](../project-management/INDEX.md)
